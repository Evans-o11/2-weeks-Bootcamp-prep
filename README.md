# 2 Weeks Bootcamp Prep

Practice projects built in the 2 weeks before starting my full-stack development bootcamp. Most of these started as class exercises, then I went back afterward on my own time  to rebuild, extend, and improve them without looking at notes. This repo is proof of that daily practice.

## About This Repo
I'm a beginner web developer based in Nigeria, currently preparing for a 6-month full-stack bootcamp. My approach: for every concept taught in class, I rebuild it solo afterward and try to push it further than the original assignment. This repo tracks that process.

## Projects in this repo

### evansportfolio.html
My personal portfolio page  About Me section, Contact section, and a "Hire Me" form. Built to practice page structure, typography, and form elements together in one real page.

### resume.html
An HTML resume  practicing semantic structure (headings, sections) the way a real resume would be laid out in code, not just plain text.

### form.html
A Farm Volunteer Worker Application Form — practicing different input types (text, radio buttons, dropdowns) and grouping related fields (like emergency contact info) logically.

### Table.html
Practice building and structuring HTML tables — rows, columns, headers.

### css.html / Style.css / intro.css
Early CSS practice files  box model, selectors, specificity, and basic styling rules applied to real markup.
